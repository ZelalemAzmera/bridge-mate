What this page proves

This page has no Bootstrap, no Tailwind, no React, no framework — just a bare HTML page. The <db-assistant> Web Component is loaded with a single <script> tag and works immediately.

⚡ One-line integration

Add these two lines before </body> on any existing website:

<script src="/module/db-assistant.js" defer></script>
<db-assistant
  lang="am"
  api="http://localhost:3000/api"
  content="/data/content.json">
</db-assistant>

Try the assistant

Use the golden 🌉 button in the bottom-right corner to open the assistant. Try:

  • Asking "What is shaping the future of VA work?" in Amharic
  • Clicking Guide Me to navigate this page by voice
  • Browsing the Jobs tab for Ethiopian tech jobs
  • Pressing Tab key only — everything is keyboard-accessible
This input exists so Guide Me can focus it.

Accessibility features

  • WCAG 2.2 AA — axe-core clean, zero critical violations
  • Keyboard-only — Tab, Enter, Escape, Arrow keys
  • Screen reader — ARIA live regions, role="dialog", role="log"
  • Focus ring — 3px solid #f5a300 (Savanna gold) on all interactive elements
  • 200% zoom — no horizontal scroll at 320px viewport
  • 6 languages — including RTL Arabic
  • Offline — BM25 search works with zero internet
